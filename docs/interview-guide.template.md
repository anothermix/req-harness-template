## ผู้ใช้งานหลัก (คนที่ทำงานนี้ทุกวัน)

**การทำงานปัจจุบัน**
- เดินขั้นตอนงานจริง 1 รอบให้ดูตั้งแต่ต้นจนจบ ใช้เครื่องมืออะไรบ้าง
- ใช้เวลาเท่าไหร่ จุดไหนเสียเวลา/ผิดพลาดบ่อยสุด
- {{คำถามเจาะ pain point เฉพาะโปรเจกต์}}

**ข้อมูลและเอกสาร**
- ข้อมูลหลักที่ใช้ (master data) มีอะไร ใครเป็นเจ้าของ อัปเดตยังไง
- เอกสาร/เลขที่เอกสาร run ยังไง ใครถือทะเบียน เคยมีปัญหาไหม
- งานซ้ำจากของเดิมมีสัดส่วนเท่าไหร่ ตอนนี้ copy ยังไง

## หัวหน้า / ผู้อนุมัติ

- ขั้นตอนอนุมัติตอนนี้เป็นยังไง อะไรทำให้ช้า
- ตอนอนุมัติดูอะไร เคย reject เพราะอะไร มีเกณฑ์ไหนอยากให้ระบบบังคับเลย
- อยากเห็นรายงาน/ตัวเลขอะไร วันนี้ได้จากไหน
- ต้อง import ข้อมูลเก่าย้อนหลังไหม ย้อนแค่ไหน

## Admin / เจ้าของกระบวนการ

- ฟอร์ม/เอกสารที่เกี่ยวข้องอยู่ใต้ระบบควบคุม (ISO ฯลฯ) ไหม แก้ได้แค่ไหน ต้องขอใคร
- ทะเบียน/ฐานข้อมูลปัจจุบันเก็บที่ไหน ใครดูแล

## IT

- นโยบายระบบใหม่: on-premise หรือ cloud, มี SSO/AD ให้เชื่อมไหม
- ระบบข้างเคียงที่อาจต้องเชื่อม มีอะไรบ้าง มี API ไหม
- ข้อกำหนด security / ข้อมูลส่วนบุคคล (PDPA) ที่ต้องผ่าน ใคร review

## ปิดท้ายทุกกลุ่ม

- ถ้าระบบนี้ทำได้แค่ 3 อย่าง อยากได้อะไรสุด
- อะไรที่ระบบ *ไม่ควร* ไปยุ่ง (สิ่งที่วันนี้ทำงานได้ดีอยู่แล้ว)
- มีใครอีกที่เราควรไปคุยด้วย
